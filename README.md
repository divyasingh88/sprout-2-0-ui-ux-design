# Sprout 2.0 — UI/UX Redesign 🌱

A responsive UI/UX redesign concept for Sprout, a mobile investing app for first-time investors in India. Built using HTML, CSS, and basic JavaScript.

## 🎯 Project Overview

Sprout aims to make the investing journey more approachable for beginners. This project redesigns the website homepage and the first five onboarding screens as one continuous user experience, from discovering the platform to preparing for a first investment.

The design focuses on simplifying financial information, improving user confidence, and making the onboarding process clearer.

## ✨ Key Features

- **Responsive Homepage:** Mobile and desktop layouts with a clear value proposition and call to action.
- **Five Onboarding Screens:** A guided journey covering welcome, getting started with ₹100, document preparation, KYC, and the first investment.
- **Consistent Branding:** A sprout-inspired mascot and visual identity shared across the website and onboarding screens.
- **Beginner-Friendly UI:** Clear instructions, simple language, and visible progress indicators.
- **Accessibility-Focused Design:** Readable typography, accessible color contrast, and comfortable tap targets.
- **Performance-Conscious Layout:** Lightweight assets and CSS-based animations.
- **Future Localization Ready:** English-first content structured to support Hindi and regional languages later.
- **Transparent Financial Messaging:** Visible risk disclaimers and no guaranteed-return claims.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🎨 Design Approach

The visual direction combines a minimal, premium fintech aesthetic with a friendly sprout-inspired mascot.

Key design principles:
- Simplicity over visual clutter
- Trust and transparency
- Mobile-first responsiveness
- Consistent design across web and onboarding
- Clear navigation and calls to action
- Accessibility and performance

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Explore the responsive homepage and onboarding experience.

No backend or package installation is required.

## 📈 Design Goals

The redesign aims to improve homepage engagement, reduce confusion during KYC, and make the first-investment journey easier to understand.

The existing conversion figures are treated as baseline indicators, not proven outcomes of this redesign.
